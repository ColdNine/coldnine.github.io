엔비디아·AMD GPU 조합해 시스템 처리량 1.22배 개선
실제 추론 데이터로 보조 모델 학습…부하 자동 최적화
모레는 미국 시카고에서 15일부터 20일까지 열리는 ‘슈퍼컴퓨팅 2026(SC26)’에서 차세대 AI 추론 최적화 프레임워크 ‘TIDE(Temporal Incremental Draft Engine)'를 발표했다고 20일 밝혔다.[사진=모레]
[디지털데일리 오병훈기자] 인공지능(AI) 인프라 솔루션 기업 모레가 대규모 언어모델(LLM) 추론 처리량을 최대 1.66배 높이는 기술을 공개했다. TIDE는 실제 AI 서비스의 추론 과정에서 생성되는 데이터를 활용해 보조 모델을 지속적으로 학습시키는 기술이다. 별도로 대형 모델을 실행해 학습 데이터를 생성할 필요가 없어 추가적인 연산 부담을 줄이면서도 실제 서비스 환경에 맞춰 보조 모델의 예측 정확도를 개선할 수 있다는 설명이다. 엔비디아 ‘H100’ GPU를 대형 모델 추론에, AMD ‘인스팅트 MI250’ GPU를 보조 모델 학습에 각각 투입한 결과 동일한 GPU 자원을 모두 추론 작업에 사용하는 방식보다 시스템 전체 처리량이 최대 1.22배 증가했다.
