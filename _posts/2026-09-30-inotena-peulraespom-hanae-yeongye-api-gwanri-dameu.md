## Summary
내부 연계(ESB)와 외부 API 게이트웨이, 개발자 포털까지 하나로… 기업 데이터 관문 일원화
인공지능 전환(AX) 전문기업 이노테나(대표 김인수·윤영호)는 내부 시스템 연계와 외부 응용프로그램 인터페이스(API) 관리를 하나의 플랫폼으로 통합한 'MI 어드밴스드 포 클라우드(MI Advanced for Cloud) V11'을 30일 공개했다. 외부 개발자와 협력사는 개발자 포털에서 필요한 API를 검색해 구독을 신청하고, 승인 후 발급받은 인증 정보로 API를 호출할 수 있다. API 제공 조직별로 카탈로그를 구분할 수 있어 계열사나 협력사에 따라 공개 범위를 다르게 설정할 수 있다. 김인수 이노테나 대표는 “AI 에이전트가 기업 업무에 들어오면서 API는 단순한 연결 통로가 아니라 기업 데이터를 지키는 관문이 됐다”며 “연계와 API를 한 플랫폼에서 같은 기준으로 관리하는 것이 AI 시대 기업 통합의 출발점”이라고 말했다.
