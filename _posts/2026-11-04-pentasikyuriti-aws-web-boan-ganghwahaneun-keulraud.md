사이버보안 전문기업 펜타시큐리티가 아마존웹서비스(AWS) 환경의 웹 보안을 강화하는 '클라우드브릭 매니지드 룰 번들(Cloudbric Managed Rules Bundles for AWS WAF)'을 출시했다고 밝혔다. 이번 제품은 클라우드 보안 서비스형 소프트웨어(SaaS) 플랫폼 '클라우드브릭(Cloudbric)'의 보안 규칙을 패키지로 구성한 것으로, 웹 애플리케이션과 응용프로그램 인터페이스(API)를 겨냥한 공격을 비롯해 악성 IP, 봇, 분산서비스거부(DDoS) 공격 등에 대응한다. '에센셜 룰 번들'은 주요 웹 취약점과 악성 IP, 봇 방어 기능을 묶어 AWS 웹 애플리케이션 방화벽(WAF)의 규칙 용량 단위(WCU) 사용을 최소화하면서 핵심 보안 기능을 제공한다. 정태준 펜타시큐리티 기획실장은 “웹 애플리케이션을 겨냥한 위협이 갈수록 지능화·자동화되고 있다”며 “이번 제품은 여러 보안 규칙을 관리하는 부담과 사용료에 대한 고민을 줄이면서 간편한 배포와 예측 가능한 비용, 강화된 보안 기능을 제공한다”고 말했다.
